# Дипломный проект по автоматизации тестирования
Автоматизированное тестирование веб-приложения aqa-shop.jar.

В рамках проекта автоматизировано тестирование формы «Купить» с проверкой пользовательского интерфейса и данных в базе данных MySQL.

## Технологии

* Java 11
* Gradle
* JUnit 5
* Selenide
* MySQL 8.0
* Docker / Docker Compose
* JDBC
* Allure

## Требования к окружению

Перед запуском проекта необходимо установить:

1. **Java 11**
2. **Docker Desktop**
3. **Git**
4. **Google Chrome**

Проверить установку Java:

```bash
java -version
```

Должна использоваться Java 11.

Проверить Docker:

```bash
docker --version
docker compose version
```

Проверить Git:

```bash
git --version
```

## 1. Клонирование проекта

Склонировать репозиторий:

```bash
git clone <ССЫЛКА_НА_ВАШ_РЕПОЗИТОРИЙ>
```

Перейти в каталог проекта:

```bash
cd aqa-diplom
```

## 2. Запуск базы данных

Проект использует MySQL 8.0, запущенный в Docker-контейнере.

Запустить контейнер:

```bash
docker compose up -d
```

Проверить состояние контейнера:

```bash
docker compose ps
```

Контейнер MySQL должен находиться в состоянии `Up`.

В проекте используется подключение:

```text
Host: localhost
Port: 3307
Database: app
User: app
Password: pass
```

Порт `3307` используется для подключения к MySQL с хоста, поскольку стандартный порт `3306` может быть занят другим экземпляром MySQL.

## 3. Запуск приложения

Приложение находится в каталоге:

```text
artifacts/aqa-shop.jar
```

Перед запуском необходимо убедиться, что контейнер MySQL запущен.

Запустить приложение:

```bash
java -Dspring.credit-gate.url=http://localhost:9090 \
     -Dspring.payment-gate.url=http://localhost:9090 \
     -jar artifacts/aqa-shop.jar
```

После запуска приложение доступно по адресу:

```text
http://localhost:8080
```

После запуска необходимо оставить приложение работающим.

## 4. Проверка доступности приложения

Открыть в браузере:

```text
http://localhost:8080
```

Должна открыться главная страница приложения с названием:

**«Путешествие дня»**

и кнопки:

**«Купить»**, **«Купить в кредит»**.

## 5. Запуск автоматизированных тестов

После запуска MySQL и приложения открыть второй терминал.

Перейти в каталог проекта:

```bash
cd aqa-diplom
```

Запустить тесты:

```bash
./gradlew clean test
```

Gradle самостоятельно выполнит сборку проекта и запустит автоматизированные тесты.

Для Windows используется:

```cmd
gradlew.bat clean test
```

## 6. Результат выполнения тестов

После выполнения тестов Gradle выводит результат в терминал.

HTML-отчёт Gradle формируется в каталоге:

```text
build/reports/tests/test/index.html
```

Открыть его можно в браузере.

## 7. Запуск тестов с формированием отчёта Allure

Для запуска тестов и получения результатов для Allure:

```bash
./gradlew clean test
```

После выполнения тестов результаты Allure находятся в каталоге:

```text
build/allure-results
```

Для формирования и просмотра отчёта Allure необходимо, чтобы Allure Commandline был установлен в системе.

Проверить установку:

```bash
allure --version
```

Запустить отчёт:

```bash
allure serve build/allure-results
```

После выполнения команды Allure откроет отчёт в браузере.

## 9. Конфигурация тестов

Настройки подключения тестов к базе данных находятся в:

```text
src/test/resources/application.properties
```

Тестовое подключение использует:

```text
jdbc:mysql://localhost:3307/app
```

Конфигурационные файлы проекта уже находятся в репозитории, поэтому после клонирования проекта дополнительные изменения конфигурации для стандартного запуска тестов не требуются.


## 10. Остановка проекта

После завершения тестирования приложение можно остановить сочетанием:

```text
Ctrl + C
```

MySQL-контейнер остановить командой:

```bash
docker compose down
```

## 11. Документация проекта

В репозитории находятся следующие документы:

* `Plan.md` — план тестирования;
* `Report.md` — отчёт о проведённом тестировании;
* `Summary.md` — отчёт о проведённой автоматизации;
* `README.md` — описание проекта и инструкция по запуску.
