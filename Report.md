## 4. Форма «Купить в кредит»

### 4.1 Позитивные сценарии

### Тест №1 — Успешная покупка в кредит с APPROVED-картой

**Тестовые данные:**
* **Номер карты:** `1111 2222 3333 4444`
* **Месяц:** `12`
* **Год:** `27`
* **Владелец:** `MANUAL TESTING`
* **CVC:** `123`

**Ожидаемый результат:**
Отображается сообщение «Успешно — Операция одобрена Банком!».
В базе данных создаётся кредитная заявка со статусом `APPROVED`, а заказ связывается с созданной кредитной заявкой через поле `credit_id`.

**Фактический результат:**
В интерфейсе отображается сообщение «Успешно — Операция одобрена Банком!».
В таблице `credit_request_entity` создана кредитная заявка со статусом `APPROVED`.
В таблице `order_entity` создан заказ, однако поле `credit_id` имеет значение `NULL`. При этом в поле `payment_id` записано значение `bank_id` кредитной заявки вместо идентификатора кредитной заявки.
**Статус: FAIL ❌**

### Тест №2 — Покупка в кредит с DECLINED-картой

**Тестовые данные:**
**Номер карты:** `5555 6666 7777 8888`

**Ожидаемый результат:**
Пользователю отображается сообщение об отказе в проведении операции. Кредитная заявка получает статус `DECLINED`, заказ не должен создаваться как успешно оформленный.

**Фактический результат:**
В интерфейсе отображается сообщение: «Успешно — Операция одобрена Банком!»
При этом в базе данных кредитная заявка имеет статус `DECLINED`.
В `order_entity` создаётся заказ, при этом `credit_id = NULL`.
**Статус: FAIL ❌**

* Найденные дефекты

DEFECT-04 - При успешной покупке в кредит заказ не связывается с кредитной заявкой
Форма: «Купить в кредит»
Ожидаемый результат: операция одобрена, в БД создаётся кредитная заявка со статусом `APPROVED`, а заказ связывается с ней через поле `credit_id`.
Фактический результат: UI показывает «Успешно — Операция одобрена Банком!».
В `credit_request_entity` создаётся кредитная заявка со статусом `APPROVED`.
В `order_entity` создаётся заказ, однако `credit_id = NULL`. В поле `payment_id` записывается значение `bank_id` кредитной заявки вместо идентификатора кредитной заявки.

DEFECT-05 - DECLINED-кредит отображается как успешный
Форма: «Купить в кредит»
Ожидаемый результат: операция отклонена, пользователю отображается сообщение об отказе. Кредитная заявка получает статус DECLINED, заказ не должен создаваться как успешно оформленный.
Фактический результат: UI показывает «Успешно — Операция одобрена Банком!»
БД: кредитная заявка имеет статус DECLINED
Дополнительно: в order_entity создаётся заказ, при этом credit_id = NULL.

DEFECT-06 — При пустом CVC появляется дополнительная ошибка у поля «Владелец»
Форма: «Купить в кредит»
Ожидаемый результат: ошибка только у CVC/CVV.
Фактический результат: у CVC отображается «Неверный формат», и дополнительно у поля владелец появляется «Поле обязательно для заполнения», фактически поле заполнено.

«Купить в кредит»: 10 PASS / 4 FAIL
Всего: 28 тестов, 21 PASS / 7 FAIL.
